Getting started

Install

Windows: run MediaRush.exe – nothing to install.
Ubuntu: install the .deb, then open MediaRush from the app menu.

Create your account

Open MediaRush, choose Create one and sign up. Your 9-digit ID is shown under Shared with me.

Connect & send

Add teammates by ID in Users, share a folder, and send files or folders.

Install on Ubuntu / Debian

sudo apt install ./mediarush_*_amd64.deb mediarush # or open MediaRush from the app menu

System requirements

  • Windows 10 or 11 (64-bit), or Ubuntu 22.04 / Debian 12 or newer (64-bit)
  • Internet connection; for transfers between sites, routers with UPnP or an open port help
  • Free disk space for the files you receive
